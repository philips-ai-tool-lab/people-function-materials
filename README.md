## 内容概况

- 原始计划分为第 1 天、第 2 天、第 2–5 天、第 7–14 天、第 14–30 天、第 30–60 天、第 90 天、第 180 天。
- 角色包括新员工、带人经理和 Buddy；涵盖团队融入、系统与资源、合规学习、产品及销售流程、客户实践和阶段回顾。
- 现有结构化模板共 54 条：员工 26 条、经理 20 条、Buddy 8 条。模板属于既有提炼，完整业务描述以原始 Word 为准。
- 总体指导描述了入职提醒与答疑的目标；Agent 文件记录基于资料回答、提供资源与说明的规则。这些内容文件不证明系统已部署或流程已验收。
